# Calkulater

Статический Astro-сайт с 289 онлайн-калькуляторами для финансов, валют, спорта, ремонта, электроники, компьютеров, геометрии, физики, работы с датами и перевода единиц.

## Что внутри

- Astro + TypeScript + Tailwind CSS.
- React Islands для интерактивных форм калькуляторов.
- Динамические страницы из `frontend/src/data/calculators.ts`.
- SEO-каркас: meta-теги, canonical, Open Graph, sitemap, robots.txt, FAQPage, BreadcrumbList, WebApplication, HowTo и Article JSON-LD.
- Интерактивный каталог `/calculators/` с поиском, быстрыми запросами, сортировкой, фильтром по категориям и no-JS fallback.
- Копирование ссылки на расчёт, копирование результата и печать/сохранение результата в PDF.
- Улучшенные карточки калькуляторов: популярность, ключевые темы, количество полей и FAQ.
- Посадочные страницы категорий с быстрыми ссылками, SEO-темами и перелинковкой.
- Сервисные страницы `/about/`, `/contacts/`, `/privacy/` для доверия и базовой юридической упаковки.
- Web manifest, favicon и OG-изображение для базовой упаковки сайта.
- Заготовки под аналитику и рекламные блоки, выключенные по умолчанию.

## Запуск локально

```bash
cd frontend
npm install
npm run dev
```

Сайт откроется на `http://localhost:3000`. Если порт занят, Astro автоматически предложит следующий свободный порт, например `http://localhost:3001` или `http://localhost:3002`.

Если нужен заранее понятный локальный порт без конфликта с основным dev-сервером:

```bash
npm run dev:local
```

Эта команда открывает dev-сервер на `http://127.0.0.1:4321`.

Если Windows только что установил Node.js и команда `npm` не находится, закройте и снова откройте терминал. В крайнем случае можно запускать через полный путь:

```powershell
cd frontend
& 'C:\Program Files\nodejs\npm.cmd' run dev
```

Если нужно быстро проверить уже запущенный локальный сайт, откройте:

- русская главная: `http://localhost:3000/ru/`;
- английский каталог: `http://localhost:3000/en/calculators/`;
- украинский пример: `http://localhost:3000/uk/valyuty/konverter-valyut/`.

Чтобы проверить именно собранную статическую версию перед деплоем:

```bash
npm run build
npm run preview:local
```

Preview откроется на `http://127.0.0.1:4322`.

## Проверки

```bash
cd frontend
npm run test
npm run build
```

Или одной командой:

```bash
cd frontend
npm run check
```

`npm run check` запускает unit-тесты, проверку публичных ассетов (favicon, manifest, OG), статическую сборку, проверку битой кириллицы, render-артефактов в HTML, внутренние ссылки в `dist`, SEO-метаданные, покрытие sitemap, служебные hosting-файлы, базовую accessibility-проверку HTML, production-hygiene и performance budget.

Перед каждой production-сборкой скрипт `prebuild` обновляет справочные курсы валют из официального XML Банка России. Обновить их отдельно можно командой:

```bash
cd frontend
npm run rates:update
```

Если официальный источник временно недоступен, скрипт сохраняет последнюю успешно сгенерированную таблицу, и сборка не ломается.

## Бюджеты производительности

Бюджеты делятся на три группы, и путать их нельзя. До разделения рантайма по
калькуляторам разницы не было — приложение было одним бандлом. Сейчас нагрузка
страницы и суммарный выпуск сборки движутся в разные стороны, и метрика,
которая их смешивает, объявляет улучшение ухудшением.

**Производительность маршрута — жёсткие блокеры.** Меряется замыкание
импортов: корни из HTML плюс всё, что они статически импортируют, без повторов.
Это то, что браузер обязан скачать на холодную загрузку одной страницы.

| Что | Потолок | Замер сейчас |
|---|--:|--:|
| JS-замыкание маршрута, gzip | 95 КиБ | 88,2 |
| HTML маршрута, gzip | 15 КиБ | 13,8 |
| HTML каталога, gzip | 5,5 КиБ + 0,42 на карточку, потолок 30 КиБ | 18,4 |
| CSS всего, gzip | 40 КиБ | 8,7 |

**Масштаб архитектуры — жёсткие блокеры.** Ловят вырождение разделения.

| Что | Потолок | Замер сейчас |
|---|--:|--:|
| Общий остров, gzip | 30 КиБ | 28,0 |
| Рантайм одного калькулятора, gzip | 8 КиБ | 1,3 |

**Масштаб сборки — наблюдение.** Суммарный выпуск важен для хостинга и как
сигнал о дублировании, но не является мерой того, что чувствует посетитель:
в `dist` лежат десять чанков калькуляторов, из которых скачивается ровно один.
Потолки здесь щедрые и намеренно не блокируют штатный рост каталога.

Три вещи, которые легко восстановить по ошибке:

- **суммарный выпущенный JS — не начальная нагрузка страницы.** При разделении
  кода он растёт, пока нагрузка страницы падает. Мерять надо замыкание;
- **суммарный HTML растёт вместе с числом маршрутов.** Каждый выпущенный
  калькулятор добавляет три локализованные страницы, поэтому абсолютный
  потолок здесь несовместим с расширением каталога. Бюджет нормирован на
  маршрут;
- **каталог — исключение и остаётся жёстким блокером.** Это одна настоящая
  страница, её вес растёт на 0,42 КиБ gzip на калькулятор (измерено 28 → 36).
  Бюджет наклонный: он пропускает добавление калькулятора, но ловит карточку,
  которая раздулась сама. Потолок 30 КиБ — это точка, где архитектуру каталога
  придётся пересмотреть, примерно на 58 калькуляторах.

Изоляция рантайма проверяется отдельно (`npm run bundle:check`): страница
одного калькулятора не должна получать реализацию другого, и общий остров не
должен содержать расчётов вовсе.

## Переменные окружения

В `frontend/.env.example` лежит безопасный шаблон. Для локальной разработки можно ничего не заполнять.

Минимум перед деплоем:

```env
PUBLIC_SITE_URL=https://your-domain.example
PUBLIC_CONTACT_EMAIL=contact@your-domain.example
```

Без `PUBLIC_SITE_URL` локальная сборка использует `http://localhost:3000`, чтобы canonical, Open Graph и sitemap были корректны для теста. Перед публикацией обязательно задайте реальный домен.

Опционально:

```env
PUBLIC_GA_ID=G-XXXXXXXXXX
PUBLIC_YM_ID=12345678
PUBLIC_SHOW_AD_PLACEHOLDERS=true
```

Если ID аналитики пустые или оставлены демонстрационными (`G-XXXXXXXXXX`, `12345678`), скрипты Google Analytics и Яндекс Метрики не подключаются.
Если `PUBLIC_SHOW_AD_PLACEHOLDERS` не равен `true`, пустые рекламные блоки не отображаются.

## Деплой

Проект рассчитан на статический деплой. Подойдут Vercel, Netlify или Cloudflare Pages.

Настройки для хостинга:
- root/build directory: `frontend`;
- build command: `npm run build`;
- output directory: `dist`;
- environment variables: значения из блока выше.

VPS для текущей версии не нужен.

## Перед публикацией

Без домена и монетизации проект уже можно тестировать локально и хранить на GitHub. Перед публичным деплоем останется:

- выбрать домен и задать `PUBLIC_SITE_URL`;
- указать рабочий `PUBLIC_CONTACT_EMAIL`;
- при необходимости подключить `PUBLIC_GA_ID` / `PUBLIC_YM_ID`;
- отдельно проверить актуальность налоговых и валютных правил;
- после подключения рекламы включать `PUBLIC_SHOW_AD_PLACEHOLDERS=true` только для подготовки рекламных мест.

## Важные заметки

- Конвертер использует официальные справочные курсы Банка России с датой обновления. Коммерческие курсы покупки и продажи, комиссии и банковский спред в расчёт не входят.
- Налоговые калькуляторы носят справочный характер: перед публикацией и использованием в реальных решениях нужно сверить актуальные правила НДФЛ и НДС.
- НДФЛ и НДС в текущей версии сверены с материалами ФНС России по состоянию на 2026 год:
  - НДФЛ: прогрессивная шкала 13/15/18/20/22% с порогами 2,4 / 5 / 20 / 50 млн ₽ в год;
  - НДС: основная ставка 22% с 1 января 2026 года, также оставлены 20% для старых документов, 10%, 0%, 5% и 7% для отдельных режимов.
- Все расчеты выполняются в браузере; сайт не сохраняет введенные пользователем значения.

## Как добавить категорию

1. Создайте `frontend/src/categories/<id>/definition.ts` и `localization.ts`.
   Определение содержит `id`, `order`, `icon`, псевдонимы поиска, три списка
   подсказок и оговорку; локализация — копирайт и вопросы по локалям.
2. Запустите `npm run categories:generate`.
3. Укажите категорию в определениях калькуляторов: `category: '<id>'`.

Больше ничего править не нужно. `CategoryId`, реестр, порядок, локализация,
вопросы, псевдонимы поиска, подсказки, оговорки, маршруты, каталог,
структурированные данные и sitemap выводятся из манифеста автоматически.

Порядок раздела задаёт поле `order`; повтор ловит генератор. Собираемые локали
(ru, en, uk) обязательны — их отсутствие валит проверку. Категория с одним
калькулятором допустима: правило связанных страниц применяется только там, где
соседи по категории действительно есть.
